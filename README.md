# 🔐 Interface de Login e Cadastro

Uma interface moderna, responsiva e intuitiva para autenticação de usuários, desenvolvida com foco na experiência de navegação e fluidez entre telas.

## Tecnologias Utilizadas

* **HTML5** — Estruturação semântica dos formulários e elementos.
* **CSS3** — Estilização moderna, alinhamento e transições visuais.
* **JavaScript** — Interatividade dos campos e controle dinâmico de exibição de telas.

## Funcionalidades

* **Exibir/Ocultar Senha:** Botão interativo nos campos de senha que permite alternar a visibilidade dos caracteres digitados, melhorando a usabilidade.
* **Alternância de Telas:** Transição simples, fluida e instantânea entre os formulários de **Login** e **Cadastro** sem a necessidade de recarregar a página.

## Como executar o projeto

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` diretamente no seu navegador de preferência.
